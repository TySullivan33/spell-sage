# Spell Sage — Web Edition
========================

Static HTML reference for the 2014 SRD 5.1 creature and spell catalog.

CONTENTS
- index.html: responsive browser app with search, filters, stat blocks, and up to three pinned comparisons.
- data.json: bundled catalog with 334 creatures and 319 spells.

PUBLISHING
Upload index.html, data.json, and .nojekyll to the root of a GitHub Pages source branch/folder. The app loads data.json using a relative URL, so it works on project Pages paths. Open the published HTTPS page to use it. Browser localStorage saves up to three pins on that browser.
